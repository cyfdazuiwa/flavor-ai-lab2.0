# 五行有缘人 · 匹配池

在「五行纳音 · 本命饮品」测试基础上扩展的社交匹配功能。用户完成测试获得五行属性报告后，
可进入匹配池，系统依据**五行生克关系**自动匹配有缘人，匹配成功双方收到通知，可选择
**开始聊天**或**继续等待**，聊天中可随时**结束聊天**。

## 功能流程

```
完成测试 → 五行报告页
              │  报告页底部出现「进入匹配池」按钮
              ▼
      填写匹配偏好（朋友 / 学习搭子 / 饭搭子 / 随缘）＋ 一句话签名
              │
              ▼
        进入匹配池（等待缘分…）
              │  系统后台每 4 秒定时扫描匹配池
              │  依据五行生克 + 偏好契合度自动撮合（≥76 分即配对）
              ▼
      匹配成功 🎊 双方收到通知（页内弹窗 + 浏览器通知 + 提示音）
              │
        ┌─────┴─────┐
        ▼           ▼
    开始聊天      继续等待（之后可随时从悬浮球/CTA 进入聊天）
        │
     结束聊天（二次确认）→ 双方聊天同步结束，档案复位，可重新入池
```

## 性别 / 年龄

- 偏好弹窗中填写：**你的性别**（男 / 女 / 保密）、**年龄**（14-99，选填）、**希望对方是**（不限 / 男生 / 女生）。
- 匹配规则：性别期望为**硬性条件**——任一方期望与对方性别不符则不撮合（保密 = 不设限）；
  期望相符 +6 分；年龄差 ≤3 岁 +4 分、≤8 岁 +2 分、>15 岁 −4 分。
- 池列表、匹配通知、聊天头部均展示「♂/♀/🔒 · 年龄」。演示机器人会自动贴合你的性别期望与年龄。

## AI 话题助手

聊天面板内置「✨ AI 话题助手」（纯前端规则引擎，不依赖外部服务、不上传任何聊天数据）：

- **破冰**：还没说过话时，依据五行生克关系、合拍度、双方本命饮品、签名、偏好生成开场白；
- **接话**：收到对方消息后，按关键词（喝/吃/学/累/哈哈/再见/疑问句…）生成情境回复；
- **邀约**：按你填的偏好生成收尾话术（饭搭子约干饭、学习搭子约自习…）；
- 每次给 3 条建议，点一下**填入输入框**（可修改再发送，主动权在你），「换一批」轮换话题；
- 隐私：所有建议本地生成，聊天记录仅存于浏览器本地。

## 五行生克匹配算法

以两人**主属性**（报告页五行分布的最高项）计算生克关系，叠加偏好契合度：

| 关系 | 基础分 | 说明 |
|------|--------|------|
| 相生（木生火、火生土、土生金、金生水、水生木） | +28 / +26 | 能量滋养、越处越旺 |
| 同气（同为一行） | +20 | 气质相投 |
| 相克（木克土、土克水、水克火、火克金、金克木） | +8 ~ +10 | 互补制衡、需要磨合 |

叠加项：双方偏好一致 +10 / 一方随缘 +6 / 双方随缘 +9；寒温互补 +5；气泡相同 +2。
合拍度 = 55 + 基础分 + 叠加分（封顶 99），≥76 分自动配对，按分数从高到低贪心撮合。

示例：木生火 + 同找朋友 + 寒温互补 ≈ 98 分；金克木 + 偏好不合 ≈ 67 分（继续等待）。

## 多用户模拟架构（纯前端，无后端）

| 存储 | 内容 |
|------|------|
| `sessionStorage.wuxing_me_v1` | 当前标签页用户档案（**每个标签页 = 一位用户**） |
| `localStorage.wuxing_pool_v1` | 匹配池全员（版本号 CAS 写入，防并发覆盖） |
| `localStorage.wuxing_matches_v1` | 匹配记录（含生克关系、合拍度、结束状态） |
| `localStorage.wuxing_chat_v1_*` | 每段聊天的消息 |
| `BroadcastChannel('wuxing-match-bus')` | 跨标签页实时通知（匹配成功 / 聊天 / 结束） |
| `localStorage.wuxing_scan_lock_v1` | 扫描心跳锁（同一时刻只有一个标签页执行撮合） |

- **两个浏览器标签页即可演示双人匹配**：各自完成测试入池，后台扫描自动撮合，双方同时收到通知。
- **单人体验**：匹配池面板中点「邀请一位有缘人入池（演示）」召唤模拟用户；入池 7~15 秒后也会
  自动来一位高合拍有缘人。机器人聊天会自动回复。
- 双人同浏览器演示时可在控制台执行 `sessionStorage.setItem('wxm_solo_off','1')` 关闭自动召唤。

## 属性标签与真人化

- **标签**：偏好弹窗可自选 2-4 个标签（#爬山 #健身 #i人 #e人 #咖啡续命 #夜猫子 等 22 个）。
  全链路展示：匹配池列表、匹配成功卡片（双方）、聊天头部、社区帖子作者。
  匹配加分：每个共同标签 +4（封顶 +12），缘由中会写「共同爱好：xxx，话题不愁」；
  卡片上**共同标签高亮**显示。
- **有缘人真人化**：每位模拟有缘人有完整人设——职业（设计师/研究生/咖啡师/宠物医生…）、
  当前状态（刚下班/在图书馆/深夜emo…）、个性签名、3 个兴趣标签（有概率与你重合），
  性别与年龄会贴合你的期望。
- **本地聊天引擎升级**（未接入大模型时）：回复结合对方人设（职业/状态/签名）、你们的共同标签、
  以及你最后一条消息的关键词（吃饭/累/哈哈/疑问句…）动态生成；同一会话内不重复；
  打字时长与回复长度相关，更像真人。接入大模型后这些素材全部进入人设 prompt。

## 接入真实大模型

聊天回复与 AI 话题助手支持接入**任意 OpenAI 兼容接口**（OpenAI / DeepSeek / Kimi / 智谱 GLM / 通义 / 本地 Ollama 等）：

1. 匹配池面板 → 「🤖 接入真实大模型」
2. 填接口地址（含 /v1）、API Key、模型名 → 「测试连接」→ 「保存」

- 接入后：机器人以有缘人**人设**续写对话（五行、饮品、偏好、签名都进 prompt），
  AI 话题助手建议也由大模型生成（标注模型名）；
- 未接入或调用失败时，自动回退本地模拟回复，功能不中断；
- **Key 只保存在本机浏览器**，请求由浏览器直连你填的服务商，不经任何中间服务器。

## 五行社区

按**本命五行**分为五个社区（木 / 火 / 土 / 金 / 水），入口：右下角「🏯 五行社区」悬浮球。

- **发帖**：以自己的五行档案（名字 / 性别年龄 / 本命饮品）发布，默认进入自己的本命社区，也可切换频道；
- **评论**：每条帖子可楼中楼评论；
- **点赞**：❤️ 按用户去重，可取消；
- **AI 代写**：发帖框支持一键生成搭子招募帖（接入大模型后更自然）；
- 首次访问自动注入 6 条演示帖让社区不冷场；跨标签页实时刷新（BroadcastChannel）；
- 未完成测试可浏览，发帖需完成测试。

## 测试

- 单用户全流程（答题 → 标签/性别/年龄入档 → 机器人配对 → 真人化 AI 聊天 → 社区 → 大模型设置）：`26/26 通过`
- 双标签页真实双人（入池 → 相生配对 98% → 跨页聊天 → 对方结束同步）：`11/11 通过`
- 匹配算法分布：相生均值 97 > 同气 89 > 相克 77（基准偏好下），阈值 76 生效

## 已知限制

- 同一浏览器的多个标签页共享 `wuxing_username`，双开测试时两人显示名称会相同
  （uid / 五行 / 匹配逻辑互不影响）；真实场景各设备各自命名，无此问题。
- 匹配池为纯前端模拟，部署到公网后所有访客共享的是各自浏览器的本地存储；
  如需真正的线上匹配池，可将 `matching/wuxing-match.js` 中数据层替换为 WebSocket 服务。
